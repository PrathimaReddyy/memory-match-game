Memory Match Game 🧠

This is a simple memory matching game I made using HTML, CSS and JavaScript.

The main idea of the game is to flip the cards and find all the matching pairs.

Features

- Card matching game
- Timer
- Move counter
- Different difficulty levels
- Restart button
- Play again option
- Best score

Technologies Used

- HTML
- CSS
- JavaScript

How to Play

1. Open the game.
2. Click on a card to reveal it.
3. Click another card and try to find its matching pair.
4. Keep matching cards until all pairs are found.
5. Try to complete the game in fewer moves and less time.

## Project Files

- `index.html` - Game structure
- `style.css` - Styling
- `script.js` - Game logic

While making this project, I learned about JavaScript events, DOM manipulation, arrays and basic game logic.
